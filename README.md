# NASA Application — Fake

A fictional NASA-style application portal made as a website prop for a game cutscene. It is not an official NASA website and is not affiliated with NASA.

## Run it
Open `index.html` in a browser. No build tools or server are required.

## Files
- `index.html` — page structure and application form
- `style.css` — layout and styling
- `script.js` — form validation and confirmation screen
- `images/` — instructions for adding replacement images

## Important
The form is a visual prop only. Submitting it does not send, save, or upload any personal information.
